# bergamot_translator

Offline, on-device translation for Mozhi with **Mozilla's open Firefox
Translations models** and the open-source **Bergamot** engine (no Google
services), plus on-device language identification with **CLD2** compiled
into the same library. Implements `OfflineTranslator` from
`translation_repository`.

Design, decision record, measurements and the app-integration checklist:
[`docs/offline-engine.md`](../../docs/offline-engine.md).

## Usage

```dart
import 'package:bergamot_translator/bergamot_translator.dart';

final translator = BergamotTranslator(
  catalog: await loadBundledCatalog(),
  root: appPrivateDirectory, // models go to <root>/models/<pair>/<version>/
  isMeteredConnection: isMetered, // Future<bool> Function()
);

await translator.downloadLanguage('de'); // de-en + en-de, SHA-256 verified
final german = await translator.translate(
  'Hello, how are you?',
  source: 'en',
  target: 'de',
); // "Hallo, wie geht es dir?" (in a background isolate)
```

Other pairs pivot through English (`es` -> `de` needs Spanish and German).
`translate` never downloads; missing models throw
`OfflineModelMissingException`.

```dart
await translator.identifyLanguage('Guten Morgen'); // 'de' (CLD2, background isolate)
await translator.identifyLanguage('OK'); // null: too little to tell
```

## Layout

| Path | What |
| --- | --- |
| `lib/` | Dart: catalog, router, model manager, chunker, language identification (CLD2 decision + heuristic fallback), FFI engine and identifier (`lib/src/engine/ffi/`, behind a conditional import so web builds work) |
| `assets/catalog.json` | 113 released Firefox directions with URLs, sizes, SHA-256 (generated by `../../tool/offline_catalog.py`; do not edit) |
| `native/` | C API (`src/mozhi_bergamot.h`), CMake build, pinned submodules (`third_party/`: translations, pcre2, cld2), `patches/`, `THIRD_PARTY_NOTICES.md` |
| `android/` | Gradle `externalNativeBuild` (NDK 28.2.13676358, arm64-v8a / armeabi-v7a / x86_64) |
| `tool/fetch_native_deps.sh` | checks out the native sources (only what the engine needs) and applies the patches |
| `tool/build_native_linux.sh` | builds `build/native/linux/libmozhi_bergamot.so` for desktop tests |

## Building and testing

```sh
# Native sources (once per checkout; also needed before any Android build)
packages/bergamot_translator/tool/fetch_native_deps.sh

# Unit tests (mocks only), from packages/bergamot_translator
# (agents: through the Very Good CLI test tool, see CLAUDE.md)
flutter test

# Real engine + real models (downloads ~100 MB from Mozilla's bucket)
tool/build_native_linux.sh
BERGAMOT_TEST_MODELS=1 flutter test test/src/bergamot_integration_test.dart
```

Tests that only need the library (language identification in
`test/src/isolate_language_identifier_test.dart`, engine errors) run
whenever it is built and are skipped otherwise. `BERGAMOT_LIBRARY_PATH`
overrides the library path, `BERGAMOT_TEST_CACHE` the model cache (default
`build/test_models`). For CLD2's raw answers, build the CLI (`cmake
--build build/native/linux --target mozhi_bergamot_cli`) and run
`build/native/linux/mozhi_bergamot_cli --detect < lines.txt`.

Regenerate the catalog (streams every model once to compute checksums;
cached afterwards):

```sh
python3 tool/offline_catalog.py
```
