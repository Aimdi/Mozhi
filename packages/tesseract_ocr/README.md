# tesseract_ocr

On-device text recognition (OCR) for Mozhi with the open-source
**Tesseract** engine (LSTM recognizer, Apache-2.0) and its **tessdata_fast**
language data, without Google services. Used by photo and camera
translation in the default (Google-free) build.

User documentation: [`docs/text-recognition.md`](../../docs/text-recognition.md).

## Usage

```dart
import 'package:tesseract_ocr/tesseract_ocr.dart';

final ocr = TesseractOcr(
  catalog: await loadBundledTessdataCatalog(),
  root: appPrivateDirectory, // data goes to <root>/tessdata/<code>.traineddata
);

ocr.catalog.forAppLanguage('de'); // TessdataLanguage(deu), 1.5 MB
await ocr.download('deu'); // SHA-256 verified, resumable; only when asked

// Pixels decoded by the app with dart:ui (rawRgba), long side <= ~2500 px.
final result = await ocr.recognize(rgba, width, height,
    languages: ['deu', 'eng']); // in a background isolate
result.text; // "Öffnungszeiten\nMontag bis Freitag"

// Where the text is: blocks, paragraphs, lines and words with their boxes
// (pixels of this image), confidences, baselines, paragraph direction,
// alignment and the colours of its text and ground.
final read = await ocr.recognize(rgba, width, height,
    languages: ['deu'], layout: true);
final paragraph = read.layout!.paragraphs.first;
paragraph.box; // OcrBox(26, 30, 316, 109)
paragraph.background; // 0xFFFFFF
paragraph.lines.first.words.first.text; // "Öffnungszeiten"
```

`recognize` never downloads: missing data throws
`TessdataMissingException`. `importFiles` installs `.traineddata` files
copied to the device by hand (matched by name, or by size and SHA-256),
without any network request.

## Layout

| Path | What |
| --- | --- |
| `lib/` | Dart: catalog (with the app-code mapping), `TessdataManager` (download, resume, verify, atomic install, import, delete), `TesseractOcr`, the FFI engine in a background isolate (`lib/src/engine/ffi/`, behind a conditional import so web builds work) |
| `assets/catalog.json` | 110 languages with URLs, sizes and SHA-256 (311 MB in all, median 2.4 MB; generated by `tool/tessdata_catalog.py`; do not edit) |
| `native/` | C API (`src/mozhi_tesseract.h`), CMake build, pinned submodules (`third_party/`: tesseract 5.5.3, leptonica 1.87.0), smoke-test CLI, `THIRD_PARTY_NOTICES.md` |
| `android/` | Gradle `externalNativeBuild` (NDK 28.2.13676358, arm64-v8a / armeabi-v7a / x86_64) |
| `tool/fetch_native_deps.sh` | checks out the native sources (shallow, pinned) |
| `tool/build_native_linux.sh` | builds `build/native/linux/libmozhi_tesseract.so` (and the CLI) for desktop tests |

What the native library contains: Tesseract's LSTM recognizer and layout
analysis, Leptonica's image processing. Not built: Tesseract's legacy
engine (so no `osd.traineddata`), training tools, ScrollView, OpenMP,
libarchive, libcurl, libtiff; Leptonica's image codecs (PNG, JPEG, TIFF,
GIF, WebP, JPEG 2000, zlib). Images come in as raw pixels. Only the eight
`mozhi_tesseract_*` functions are exported (C API version 2, with
`mozhi_tesseract_recognize_layout`, which returns the layout as JSON);
libc++ is linked statically.

## Building and testing

```sh
# Native sources (once per checkout; also needed before any Android build)
packages/tesseract_ocr/tool/fetch_native_deps.sh

# Unit tests (mocks only), from packages/tesseract_ocr
# (agents: through the Very Good CLI test tool, see CLAUDE.md)
flutter test

# Real engine: build the library and fetch English (4 MB), then test again
tool/build_native_linux.sh
mkdir -p build/test_tessdata && curl -L -o build/test_tessdata/eng.traineddata \
  https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/87416418657359cb625c412a48b6e1d6d41c29bd/eng.traineddata
flutter test test/src/native_engine_test.dart
```

The real-engine tests are skipped while the library or `eng.traineddata`
is missing. `TESSERACT_LIBRARY_PATH` overrides the library path,
`TESSERACT_TEST_TESSDATA` the data directory (the cache of
`tool/tessdata_catalog.py` is used too). Smoke test or benchmark on any
image (8-bit binary PGM/PPM):

```sh
convert photo.jpg -resize '2500x2500>' photo.ppm
build/native/linux/mozhi_tesseract_cli build/test_tessdata eng photo.ppm
# the layout (JSON with blocks, paragraphs, lines, words and colours)
build/native/linux/mozhi_tesseract_cli --layout build/test_tessdata eng photo.ppm
```

Regenerate the catalog (downloads every listed file once, 311 MB, cached
in `build/tessdata_cache/<commit>/`):

```sh
python3 tool/tessdata_catalog.py            # or --commit <sha> to move on
```
