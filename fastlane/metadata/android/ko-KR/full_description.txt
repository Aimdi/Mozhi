Mozhi 번역은 계정, 광고, 추적이 없는 개인정보 보호 번역기입니다. 휴대전화에서 직접, Mozhi 서버(Google, DeepL 등을 위한 오픈소스 프런트엔드)를 통해, 또는 직접 선택한 AI 모델로 클라우드나 내 컴퓨터에서 번역할 수 있습니다.

기본적으로 비공개
• 오프라인 우선: 언어 쌍이 설치되어 있으면 휴대전화에서 번역하고, 그렇지 않으면 텍스트를 온라인으로 보내기 전에 Mozhi가 확인합니다. ‘오프라인 전용’ 또는 ‘온라인’을 선택할 수도 있습니다
• 텍스트는 직접 선택한 서비스로만 전송되며, 번역마다 누가 받았는지 표시됩니다
• 텍스트를 온라인으로 보낼 때 이메일 주소, 전화번호, IBAN, 카드 번호, IP 주소는 휴대전화에 남습니다
• 암호화된 기록은 Android 클라우드 백업에서 제외되며, 시크릿 모드, 앱 잠금, 모든 네트워크 요청 목록을 제공합니다
• 분석, 원격 측정, 비정상 종료 보고, Google 코드가 없습니다

휴대전화에서 오프라인으로
• Mozilla의 Bergamot 엔진과 Firefox Translations 모델로 약 55개 언어 지원
• Whisper 음성 인식, Tesseract 텍스트 인식, 기기 내 AI 모델
• 탭할 때만 다운로드되고 사용 전에 검사되며, 파일에서 가져올 수도 있습니다. 미러를 사용하지 않으면 배포처(Google Cloud의 Mozilla, Hugging Face, GitHub)에 IP 주소가 보입니다

원할 때는 온라인으로
• 공개 Mozhi 서버가 내장되어 있고 직접 운영하는 서버도 쓸 수 있으며, 자동 장애 조치를 지원합니다. 공개 서버는 다른 사람이 운영하므로 운영자와 해당 엔진이 보낸 내용을 읽을 수 있습니다
• 내 키로 OpenAI, Anthropic, Gemini, OpenRouter, Mistral 또는 OpenAI 호환 서버 사용, Ollama, LM Studio, llama.cpp로 로컬 모델 사용, DeepL API와 LibreTranslate 지원
• 엔진 비교로 결과를 나란히 비교하고, ‘빠름’과 ‘고품질’ 엔진을 한 번의 탭으로 전환

AI 부가 기능
• 어조, 읽기 수준(CEFR A1~C2), 성별, 맥락, 용어집, 프리셋, ‘해적 말투’ 같은 사용자 지정 언어
• 다듬기(‘더 격식 있게’, ‘더 짧게’, ‘더 쉽게’ 등), 다른 번역, 인사이트, 설명
• 의미 확인: 역번역으로 의미가 달라진 부분을 알려 줍니다
• 교정과 사전

카메라, 문서, 음성
• 실시간 카메라와 사진: 텍스트를 휴대전화에서 인식하고 그 위에 번역을 표시합니다
• 문서의 서식과 레이아웃 유지: PDF, Word, PowerPoint, Excel, OpenDocument, EPUB, 자막 및 현지화 파일
• 마주 보고 하는 대화, 또는 같은 Wi-Fi에 연결된 게스트의 휴대전화와 공유
• 강연 받아쓰기와 다른 앱 소리에 자막 표시(Android 10 이상), 인식은 휴대전화에서 처리

일상 속 번역
• 입력하는 즉시 번역, 언어 감지, 단어를 탭하여 찾아보기
• 모든 앱의 선택 메뉴에 ‘Mozhi로 번역’과 ‘오프라인 번역’ 추가, 화면 번역, Mozhi로 공유, 빠른 설정 타일과 위젯
• 즐겨찾기, 회화집, 플래시카드 연습
• 암호화된 백업, 직접 운영하는 WebDAV 서버를 통한 동기화, 휴대전화 간 전송
• Material You, 어두운 테마, 태블릿 레이아웃, 스크린 리더 레이블

Mozhi 번역은 무료 오픈소스 소프트웨어(MIT)이자 독립적인 비공식 클라이언트입니다. Mozhi 프런트엔드(codeberg.org/aryak/mozhi)는 별도의 프로젝트이며, 이 앱은 Google, DeepL 또는 어떤 AI 제공업체와도 제휴 관계가 없습니다.
