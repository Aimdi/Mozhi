Mozhi 翻訳は、アカウント不要・広告なし・トラッキングなしのプライベートな翻訳アプリです。スマートフォン上で、Mozhi サーバー（Google や DeepL などに対応するオープンソースのフロントエンド）経由で、または選んだ AI モデル（クラウドでも自分のコンピュータでも）で翻訳できます。

初期設定でプライベート
• 「オフライン優先」：言語ペアがインストールされていればスマートフォン上で翻訳し、そうでない場合はテキストをオンラインに送る前に Mozhi が確認します。「オフラインのみ」や「オンライン」も選べます
• テキストは許可した送信先にのみ送信され、各翻訳には受け取った相手が表示されます
• デフォルトでは、翻訳するテキストをオンラインに送るときも、その中のメールアドレス、電話番号、IBAN、カード番号、IP アドレスはスマートフォン上に残ります
• 暗号化された履歴は Android のクラウドバックアップの対象外。「シークレットモード」、「アプリのロック」、アプリが送信するすべてのリクエストの一覧も
• アナリティクスなし、テレメトリーなし、クラッシュレポートなし、Google のコードなし

スマートフォンでオフライン
• Mozilla の Bergamot エンジンと Firefox Translations のモデルで約 55 言語に対応
• Whisper による音声認識、Tesseract による文字認識、デバイス上で動く AI モデル
• タップしたときにだけダウンロードされ、使用前に検証されます。ファイルからインポートすることもできます。ミラーを使わない限り、配布元（Google Cloud 上の Mozilla、Hugging Face、GitHub）にはあなたの IP アドレスが見えます

必要なときはオンライン
• 公開 Mozhi サーバーを内蔵、または自分のサーバーも使え、自動フェイルオーバーに対応。公開サーバーは他の人が運営しているため、運営者とそのエンジンは送信した内容を読むことができます
• OpenAI、Anthropic、Gemini、OpenRouter、Mistral、または任意の OpenAI 互換サーバーを自分のキーで利用。Ollama、LM Studio、llama.cpp によるローカルモデル。DeepL API と LibreTranslate
• 「エンジンを比較」で並べて比較。「高速」と「高品質」のエンジンはワンタップで切り替え

AI の追加機能
• トーン、読解レベル（CEFR A1〜C2）、性別、文脈、用語集、プリセット。「海賊ことば」のようなカスタム言語にも翻訳
• 調整（「より丁寧に」「より短く」「より平易に」など）、別の訳、インサイト、説明
• 「意味を確認」：逆翻訳で意味の違いを指摘します
• 「校正」と「辞書」

カメラ、ドキュメント、音声
• 「ライブカメラ」と写真：テキストはスマートフォン上で読み取られ、訳文がその上に重ねて表示されます。または、写真が選んだ Mozhi か AI のエンジンに送信されます
• ドキュメントは書式とレイアウトをそのまま維持：PDF、Word、PowerPoint、Excel、OpenDocument、EPUB、字幕ファイル、ローカライズファイル
• 対面での「会話」、または同じ Wi-Fi に接続したゲストのスマートフォンと共有
• 講演の「文字起こし」と他のアプリの音声への字幕表示（Android 10 以降）。認識はスマートフォン上で行います

毎日の翻訳に
• 入力しながら即時翻訳、言語の検出、「単語をタップして調べる」
• 他のアプリの選択メニューに「Mozhi で翻訳」と「オフラインで翻訳」。「画面を翻訳」、Mozhi への共有、クイック設定のタイル、ウィジェット
• 「お気に入り」、「フレーズ集」、フラッシュカードでの「練習」
• 暗号化バックアップ、自分の WebDAV サーバーを使った同期、スマートフォン間の転送
• Material You、ダークテーマ、タブレット向けレイアウト、スクリーンリーダー用のラベル
